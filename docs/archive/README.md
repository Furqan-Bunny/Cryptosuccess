# Archived documents (historical)

These documents describe the original Firebase-based plan for CryptoSuccess
(Firestore, Cloud Functions, Firebase Auth) and the first round of product
specs and epics. They are kept for history only.

**They do not describe the current system.** The app now runs on Supabase
(Postgres, Auth, Row Level Security), Vercel route handlers and crons, Stripe and
NOWPayments, a Telegram bot, and an on-chain anchored track record. Some claims in
these files (for example accuracy targets, coin coverage and feature lists) were
plans or goals, not measured results.

For the current state of the project read, in order:

1. [`../../README.md`](../../README.md) — what the product is and how to run it
2. [`../../QUICKSTART.md`](../../QUICKSTART.md) — local setup on Supabase
3. [`../HANDOVER.md`](../HANDOVER.md) — status, roadmap and operations
4. [`../DEPLOY_ENV_CHECKLIST.md`](../DEPLOY_ENV_CHECKLIST.md) — production environment
